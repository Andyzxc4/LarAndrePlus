# Character Images

Place your character images in this directory:

## Required Images

1. **andre.jpg** - Your face image
   - Recommended size: 500x500px (square)
   - Format: JPG or PNG
   - Should show your face clearly

2. **lara.jpg** - Your girlfriend's face image
   - Recommended size: 500x500px (square)
   - Format: JPG or PNG
   - Should show her face clearly

## Image Guidelines

- Use high-quality images with good lighting
- Square aspect ratio works best
- Face should be centered and clearly visible
- Avoid images with complex backgrounds
- Keep file sizes reasonable (< 1MB)

## Current Status

The application will display placeholder images if these files are not present.
Add your images here before running the application for the best experience!
