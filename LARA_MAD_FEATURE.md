# 😡 LARA GETS MAD - New Feature

## Date: November 11, 2025

### ✅ Feature Overview

When users say something negative or rude about Lara, she now gets **genuinely angry** (not just playfully jealous), and Andre steps in to calm things down and redirect the conversation.

---

## 🎭 How It Works

### Flow:
1. **User says something bad about Lara** (e.g., "Lara is annoying", "Lara is ugly")
2. **Lara responds FIRST** with genuine anger and offense
3. **Andre follows up** trying to calm things down and reset
4. **Conversation continues** normally after the reset

### This is Different From:
- **Jealousy** (when other girls are mentioned) - Playful and sassy
- **Mad** (when insulted) - Genuinely upset and defensive

---

## 🔥 Trigger Phrases

The following phrases will make Lara mad:
- "lara is ugly"
- "lara is annoying"
- "lara is stupid"
- "lara is dumb"
- "lara is bad"
- "hate lara"
- "lara sucks"
- "lara is mean"
- "lara is terrible"
- "lara is boring"
- "don't like lara"
- "lara is lame"

- **Firm boundaries** - Makes it clear the behavior isn't acceptable
- **Angry emojis** - 😠 😡 🤬

   - Updated `generate_andre_response()` to accept `lara_is_mad` parameter
   - Added calming response logic for Andre

2. **`backend/main.py`**
   - Added detection for negative phrases about Lara (priority check)
   - Added `lara_is_mad` flag
   - Passes flag to Andre's response generator

### Detection Priority:
```python
1. Check for negative comments about Lara (HIGHEST PRIORITY)
   ↓ If detected: Lara gets mad, Andre calms down
2. Check for other girl names
   ↓ If detected: Lara gets jealous
3. Random playful interruptions
   ↓ 10% chance: Lara comments playfully
4. Normal conversation
   ↓ No interruption
```
